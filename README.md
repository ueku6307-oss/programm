## Задача A. Площадь квадрата

Дан периметр квадрата — натуральное число `P ≤ 10^9`. Найти площадь квадрата, если известно,
что длина стороны квадрата также является натуральным числом.

**Вход:** `P`  
**Выход:** `S`

### Решение

Периметр квадрата `P = 4a`, значит сторона `a = P / 4`, а площадь `S = a * a`.
По условию сторона натуральная, поэтому `P` делится на 4 нацело — проверок не требуется.

Сложность: O(1) по времени и памяти.

> В C++ важна 64-битная арифметика: при `P = 10^9` площадь равна `6.25·10^16`, что не
> влезает в `int`, поэтому нужен `long long`.
